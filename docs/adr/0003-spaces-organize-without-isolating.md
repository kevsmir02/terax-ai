# Spaces organize projects without isolating their files or processes

The user chose Spaces as organizational contexts, allowing multiple Spaces to reference the same checkout and deliberate file editing outside a project root. Switching Spaces retains running processes while hidden presentation pauses and attention notifications remain available. Separate worktrees provide distinct file trees when desired; Space deletion must protect unsaved and running work and never delete project files merely because their organization was removed.

Note: Extended by [ADR-0012](0012-opt-in-space-account-isolation.md) for opt-in per-Space external-agent account isolation; files, checkouts, and OS user permissions remain shared.
