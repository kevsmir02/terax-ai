# Publish under this fork's own identity, endpoint and signing key

The fork must ship stable Linux packages without borrowing upstream's name, release channel or trust. Decided on 2026-11-13: the publication identity is the product name `Codr` (bundle identifier `io.github.kevsmir02.codr`, package/namespace `codr`, CLI sidecar `codr-cli`, environment prefix `CODR`), the release owner/repository `kevsmir02/terax-ai`, and the update endpoint `https://github.com/kevsmir02/terax-ai/releases/latest/download/latest.json`; the first stable line is `0.1.0` (amended on 2026-11-14 from the initial `1.0.0` choice so the fork starts at `0.1.0`, while keeping upstream's `v0.5.x–v0.9.x` tags out of `origin`), and release notes still state the upstream revision it derives from. Authenticity rests on a minisign key generated offline by the maintainer (key ID `94097B75DB498B21`, fingerprint `sha256:a02fd6ac492d1f070919bde106c20c0a376fbcdb6db8bc4c17ca0efd68197487`), passphrase-protected, with the secret never entering the repository, CI logs or an issue body; only the public key, its key ID, its fingerprint and non-secret configuration are committed, together with an offline recovery and replacement procedure that never bypasses verification. Managed DNF/APT repositories remain deferred, so native package/repository trust is a separate promise from artifact authenticity, and a failure in either fails closed rather than falling back. A tag produces workflow artifacts gated by `scripts/release_gate.py` that a human publishes; the gate refuses whenever identity, trust, CI evidence or signatures fail rather than skipping verification. Rejected: staying on the provisional `.invalid` identity (`Terax Workspace`), reusing upstream's identity or keys (a silent migration of someone else's users onto this fork's artifacts), and GPG-signed repositories (more machinery than a deferred repository decision needs). Consequence: every reader-facing surface states that Codr is an unofficial fork not affiliated with Crynta, and a rename later is a breaking change for the endpoint, package names and installed identity.
