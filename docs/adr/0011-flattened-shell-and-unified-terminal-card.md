# Flatten the outer shell chrome and frame terminal tabs in one unified card

Decided on 2026-11-14: replace the floating card treatment on top-level shell panels with flush hairline-divided outer chrome, place every terminal tab inside a standalone rounded outlined terminal card with an explicit perimeter margin inside the content stage, decouple the terminal surface background to sit deeper than the surrounding stage, and elevate muted chrome contrast across tabs, buttons, borders, and sidebars while leaving non-terminal views (code editors, markdown, diffs, history, and previews) full-bleed inside the stage. Split terminal tabs share that single unified outer card, separated internally by opaque one-pixel hairline dividers, opaque per-leaf pane headers showing session identity, agent activity status, and concise working directory, and an opaque card footer for the blocks-mode command composer. Rejected: keeping floating rounded cards for top-level panels (clashes with framing the terminal inside), rendering split leaves as independent rounded cards separated by visible stage gaps (breaks the single shared opaque GPU canvas geometry without introducing multi-region clear/corner masking), wiring volatile shell prompt titles into pane headers, and altering native PTY or terminal engine layers. Consequence: peripheral shell chrome can retain optional vibrancy translucency while the content stage and terminal surfaces remain opaque for high-contrast rendering and crisp separation between native chrome and full-screen dark TUIs.
