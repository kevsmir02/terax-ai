# Build a workspace around independent agents

The fork serves a personal workflow combining terminal agents, project files, editing, previews, and Git. The user chose independently installed external agents over Terax's built-in AI system, accepting the loss of integrated chat, AI editing, and supervision to reduce unwanted product complexity and maintenance. Shared terminal, file, notification, and control infrastructure remains where retained workflows need it; resource savings must be measured rather than inferred from deletion.
